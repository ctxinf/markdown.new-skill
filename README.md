# markdown.new skill
It enables an agent to fetch page content through `https://markdown.new/<url>`.

- No scripts
- Single `SKILL.md`
- title+description: 91 tokens
- content: 283 tokens
## Installation

```bash
skills add ctxinf/markdown.new-skill
```

## Dev

```sh
rm -rf .agents/skills
ln -s ../skills .agents/skills
```
